# DESIGN.md — 喫茶よふけ LP

> 出典: オリジナル企画（カンプなし・コンセプトから自作）。2026-06-12 公開。
> 架空の店舗「喫茶よふけ」（22:00–05:00 営業、眠れない夜のための深夜喫茶）のLPという設定。
> ペルソナ: 夜ふかしの人。眠れないことに少し後ろめたさがある層に「直さなくていい」と言う店。

## コンセプト — 「scroll = walk」: サイト訪問を、来店にする

普通のLPはセクションを縦に積むが、このLPは **ページ全体がCSS 3Dで作った夜の路地**。
スクロール量がカメラの前進（translateZ）に変換され、訪問者は路地を歩く。

1. **歩行ドリー**: スクロール → 目標カメラ位置 → 毎フレーム lerp(0.085) で滑らかに前進。
   マウス位置で視線がわずかに揺れる（rotateX/Y ±2〜3deg）。
2. **歩数カウンター**: スクロール率を「店まで あと◯歩」（全134歩）に変換。
   進捗バーの代わりに歩数で距離を伝え、到着で「ようこそ。」に変わる。
3. **路地の風景**: 提灯・縦書きネオン看板・自販機・木箱の上の猫（瞬きする）・鉢植え・
   電線・窓明かりを通り過ぎる。コンテンツは「立て看板」として路地に立っている。
4. **扉の演出**: 突き当たりの店構えに接近すると木の扉が観音開きに開き、
   暖色の光が路地にこぼれる。くぐると路地と夜空がフェードアウトし、
   紙色の「店内」パネルに到着する（明→暗→暖の感情曲線）。
5. **雨トグル**: 「雨を降らせる」で Web Audio のブラウンノイズ（lowpass 720Hz）と
   CSS の雨レイヤーが同時に始まる。コピー「雨の日は、ちゃんと雨の音がします」の実装。
6. **もう一度歩く**: 到着パネルのボタンで入口へスムーズスクロール（巻き戻し歩行）。

## 路地のリアリティ（2026-06-12 改修）

- 壁は1枚のグラデではなく **建物の区画**（漆喰・煉瓦・トタン・タイル）に分割。
  区画ごとに目地・錆だれ・継ぎ目の影を持ち、`--noise`（SVG feTurbulence の
  データURI）でざらつきを全面に乗せる。
- 設備ディテール: 雨樋・室外機（ファン+水染み）・シャッター・壁の注意書き
  （駐車禁止/火気厳禁、右壁は鏡写しになるので scaleX(-1) で戻す）。
- 地面: 中央のグレーチング側溝・マンホール×2・油染み・壁ぎわのAO。
- 電柱×2（電線の奥行きと位置を揃える）、ピンクのスナック看板で色相に変化。
- 店構えの扉は **本物の開口部**: ファサードを左・右・上の3ピースに分割し、
  開いた扉の奥に翻訳Zで下がった「店内」プレーン（カウンター・ボトル棚・
  吊り電球をグラデで描画）が視差つきで見える。

## 白飛び対策（スクロール時のフラッシュ）

原因: カメラ直前を通過する発光要素（窓明かり・ネオン・扉奥の光プレーン）が
通過の瞬間に巨大投影され、box-shadow ごと画面を覆っていた。

- 全要素の通過フェードを早める（near0 30→60 / near1 260→320）
- 壁の子要素の窓明かりも `--wx` から奥行きを逆算してフェード対象に追加
- 扉奥の光プレーンは専用パラメータ（near0 -20 / near1 90）で開口部内で減衰
- 扉が開いたら扉窓の発光 box-shadow を絞る
- 開扉トリガーは camTarget（スクロール目標）判定にして、
  高速スクロールでも閉じた扉をすり抜けない
- 検証: 最下部まで一気にスクロールして 300ms 刻みで10フレーム撮影 → 白飛びゼロ

## 3D実装メモ

- `.scene`(fixed + perspective 1000px) > `.camera`(視線揺れ) > `.world`(translateZ ドリー)。
- 路地は ground / wall ×2 の3枚の長いプレーン（rotateX/rotateY 90deg、原点 z=+200〜+1600）。
- 内容物は `--d`（奥行きpx）で `translateZ(-d)` に置くビルボード。残距離 = d − cam。
- スケール基準 **1m ≈ 277px**（視点高 430px ≈ 1.55m）。自販機500px・扉570px・提灯125px。
- 要素は距離でフェード（遠方は霧から滲み出し、通過直前にふっと消える）。
  ファサードのみ `data-near0/near1` 負値で「くぐり終えてから」消す。
- **既知の罠**: カメラ平面を跨ぐ長いプレーンは Chromium の preserve-3d ソートを乱す。
  入店時に壁・地面・空を opacity フェードで退場させて回避（演出と兼用）。
- 消失点は固定の霧オーバーレイ（radial-gradient）で覆い、奥の描画限界を隠す。

## フォールバック

- `prefers-reduced-motion` / JS無効 / 「平面で読む」トグル → `body.flat` で
  通常の縦並びカードに切替（コンテンツは同一DOM・セマンティックな section/h2/dl）。
- `<body class="flat no-js">` で開始し JS が解除する Progressive Enhancement。
- iframe サムネイル（gallery一覧）では初期視点＝路地の入口がそのまま絵になる。

## Visual Theme

- **藍の夜 × 行灯の橙**。濃紺のグラデ夜空に月、暖色の窓明かり・提灯・ネオン。
- 自販機のシアン (#8fe8dd) だけ補色系で「日本の夜道」の記号として効かせる。
- 到着した店内だけ紙色 (#f2e7d0) ベース。夜道の寒色 → 店の暖色への反転が報酬。
