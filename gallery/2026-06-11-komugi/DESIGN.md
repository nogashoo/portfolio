# DESIGN.md — こむぎの時間 Bakery & Morning LP

> 出典: ユーザー支給のデザインカンプ（PC / SP 両画面）。
> 本ファイルはカンプから抽出したデザイントークンの定義。UI 生成時はこの値のみ使用する。
> Phase 1（ヒアリング）/ Phase 2（参考サービス選定）はカンプ支給のためスキップ（2026-06-11）。

## Visual Theme

- 小さなまちの焼きたてパン屋。**温かい・素朴・手仕事感**。
- クラフト紙のようなクリーム〜ベージュの背景に、こげ茶のテキスト。
- 装飾は手描き風の細線アイコン（麦・瓶・オーブン・小枝）のみ。光沢・グラデーション禁止。
- 写真は実写のパン写真を角丸で使用。イラストはコーヒーカップ等の線画のみ許可。

## Typography

- 見出し・ロゴ: **Zen Maru Gothic**（500 / 700）— カンプの丸く柔らかい和文見出しを再現
- 本文: **Noto Sans JP**（300 / 400 / 500）
- 見出しは `letter-spacing: 0.08em〜0.14em`（カンプはかなり字間が広い）
- 本文 `line-height: 1.8`、注釈 1.7
- 価格は `font-feature-settings` 不要、Zen Maru Gothic 500

## Layout Principles

- コンテナ `max-width: 1080px`（カンプはやや狭め）
- セクション間 `clamp(72px, 9vw, 120px)`（カンプは密だが LP として余白を広げる方針 = ユーザー指示）
- 角丸: カード 16px / 写真 12px / ボタン 8px / バッジ 4px
- セクション見出しは中央寄せ + 左右に細線（カンプの「こだわり」「人気商品」見出しスタイル）
- ブレークポイント: 480 / 768 / 1024px、モバイルファースト

## Components

- **OPENバッジ**: 深緑地 + 白文字、角丸4px。営業ステータス文と並べる
- **営業情報カード**: 白カード、ヒーロー右に重ねる（SPはヒーロー下に重ね気味に配置）
- **Googleマップボタン / 電話ボタン**: こげ茶地 + 白文字、▶ or 受話器アイコン
- **商品カード**: 写真（正方形・角丸）+ 商品名 + 価格。PC は5列、SP は横スクロール（scroll-snap + ドット）
- **焼き上がりタイムテーブル**: 時刻 + 品目の罫線リスト、時計アイコン
- **NEWバッジ**: 焼き色オレンジ枠 or 地 + 白文字、日付は text-light
- **モーニング予告カード**: ベージュ地 + 手描き線画（コーヒー）+ 角丸大きめ、紙っぽい質感

## セクション構成（上から）

1. ヘッダー（スティッキー / SP はハンバーガー）

8. モーニング予告（2024年秋ごろ開始予定）

11. フッター（ダークブラウン、電話CTA、Instagram / LINE、コピーライト）

## Do's and Don'ts

- Do: 実写パン写真、角丸、細線アイコン（カスタムSVG）、たっぷりの余白
- Do: 営業ステータスは JS で曜日・時刻から自動判定してよい
- Don't: 紫・ネオン・グラデーション、グラスモーフィズム
- Don't: Inter / Roboto、絵文字アイコン、Lucide
- Don't: パララックス・パーティクル。アニメは fade-up 程度
- Don't: 純白 `#FFF` 背景
