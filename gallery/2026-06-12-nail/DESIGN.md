## Visual Theme

- ママ向けの自宅プライベートネイルサロン。**やさしい・上品・癒し**。
- ピンクがかった生成り背景に、ダスティピンクのアクセントとブラウンのテキスト。
- 装飾は手描き風の小枝（ボタニカル）線画と破線のみ。光沢・グラデーション禁止。
- ロゴ・英字アクセントは筆記体（Great Vibes）。

## Typography

- ロゴ・英字見出し: **Great Vibes**（筆記体、カンプの "Lily nail" ロゴ再現）
- 見出し: **Noto Serif JP**（400/500/600）— カンプの明朝見出しを再現
- 本文: **Noto Sans JP**（300/400/500）
- 見出し `letter-spacing: 0.1em〜0.12em`、本文 1.7〜1.9

1. ヘッダー（スティッキー。ロゴ + ナビ + ピンクの LINE ピルボタン / SP はハンバーガー）

   - うるうるニュアンス ¥7,000〜/90min・シンプルオフィス ¥6,500〜/90min・
     フラワー×シェル ¥7,500〜/100min・マグネット×ミラー ¥7,000〜/90min ほか

   + 丸写真 + Nailist Rina バッジ（ネイリスト歴7年・JNEC1級保有）— 7:5 非対称 2 カラム
4. 特徴 4 項目（お子様連れOK / 完全プライベート空間 / 丁寧なカウンセリング / 衛生管理の徹底）
5. メニュー・料金（破線罫の料金表。ナビにあるためカード価格から導出して追加）
6. 新着デザイン（PC 5 点グリッド / SP 3 点 + 一覧を見る→）
7. お客様の声（写真 + 引用 + 属性 + 金色★5 の横長カード×3）
8. ご予約・お問い合わせ（二重ピンク枠 + 小枝 + LINE 緑ボタン + フォーム外枠ボタン）
9. フッター（ライトピンク地、筆記体ロゴ + ナビ + コピーライト）
10. SP のみ: 固定フッタータブバー（トップ/ギャラリー/メニュー/サロン案内/予約・問合せ、ピンク地）

## Components

- **New ラベル**: ライトピンク地 `#F6D9DF` + ピンク文字、角丸 3px、写真左下
- **LINE ボタン**: 緑 `#06B053` + 白文字 + 吹き出しアイコン、サブテキスト「24時間受付中」
- **ヘッダー予約ボタン**: ダスティピンクのピル型（メイン+サブ 2 行）
- **Rina バッジ**: ライトピンクの正円、筆記体 "Nailist Rina" + 資格表記、写真右上に重ねる
- **問い合わせ枠**: ピンク 1px 枠 + 内側にライトピンクの二重線（カンプのフレーム・ボックス）
- **区切り線**: ピンクの破線 + 中央に小枝モチーフ
- **スライドドット**: アクティブ=ピンク / 非アクティブ=ベージュ

## Do's and Don'ts

- Do: 実写ネイル写真（Unsplash）、角丸、ボタニカル線画（カスタムSVG）、破線
- Do: SP は固定タブバー + ハンバーガードロワーの 2 系統ナビ（カンプ準拠）
- Don't: 紫・ネオン・グラデーション、グラスモーフィズム、パララックス
- Don't: Inter / Roboto、Lucide、丸背景色付きアイコン
- Don't: 純白 `#FFF` 背景
