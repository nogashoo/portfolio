# DESIGN.md — ヒダリ文具店 LP

> 出典: オリジナル企画（カンプなし・コンセプトから自作）。2026-06-11 公開。
> ペルソナ: **左利きの人**（人口の約10%）。市販のハサミ・定規・急須・ノートに
> 毎日小さなストレスを感じながら「自分が不器用なせい」と思ってきた層。
> 架空の店舗「ヒダリ文具店」（東京・蔵前、週3日営業）のLPという設定。

## コンセプト — 「ページ自体が左利きの体験装置」

普通のLPは商品を「見せる」が、このLPは右利きの訪問者に
**左利きの違和感を一瞬体験させてから**商品を見せる。

1. **鏡文字ヒーロー**: 見出し「世界は、右利き用にできている。」が初回は
   `scaleX(-1)` の鏡文字で表示される。読みづらい——その違和感こそが本文。
   ボタン押下 or スクロールで1行ずつ反転して戻る（stagger 180ms）。
2. **鏡写しヘッダー**: 世間の慣習と左右逆（ナビが左・ロゴが右）。
3. **逆目盛り定規ディバイダ**: セクション区切りが「30→0」の左利き定規。
4. **体験セクション**: 朱ベタ面で本文が常時鏡文字。ボタンを
   「押しているあいだだけ」正しい向きに戻る（pointerdown/up + キーボード対応）。
5. **左端レール**: 縦書き「こちら側が、ヒダリ。」を `mix-blend-mode: difference` で常設。
6. **CTAの矢印も左向き**（→ではなく←）。gallery-return ピルが画面左下なのも偶然テーマに合う。

## Visual Theme

- **墨 × 生成り × 朱のエディトリアル・マニフェスト**。意見広告・宣言文のトーン。
- ヒーローと観察記録セクションは墨ベタ、体験セクションは朱ベタ。明暗を大きく往復させる。
- 装飾はインラインSVGの線画（ハサミ・ノート・定規・急須）のみ。写真不使用。
- 縦書き（`writing-mode: vertical-rl`）を随所に使い和文エディトリアルの空気を出す。

## Color Palette

| Token | HEX | 用途 |
|---|---|---|
| `--ink` | `#1C1914` | 墨。ヒーロー/観察記録/フッター背景、本文テキスト |
| `--ink-soft` | `#3A352C` | 本文サブ |
| `--paper` | `#F3EDDE` | 生成り。ベース背景・暗部の文字色 |
| `--paper-deep` | `#E9E1CD` | 定規帯・商品図版の地 |
| `--vermilion` | `#CF3A23` | 朱。アクセント・体験セクション背景・左利きドット |
| `--mist` | `#8B8472` | キャプション |
| `--line` | `#D5CAB1` | 罫線 |

`::selection` は朱地に生成り文字。グレインオーバーレイ（SVG feTurbulence）で紙の質感。

## Typography

- 見出し: **Shippori Mincho B1**（600 / 700 / 800）— 太い明朝で宣言文の強さを出す
- 本文: **Zen Kaku Gothic New**（400 / 500 / 700）
- ヒーロー見出し `clamp(46px, 9.2vw, 124px)`、字間 0.04em
- セクションラベルは 0.28em の広字間 + 朱の横棒
- 観察記録の番号は `-webkit-text-stroke` の朱アウトライン数字

## Layout / Motion

- 観察記録: 2カラムで偶数項目を `translateY(26px)` 下げた段差リズム
- 道具: 2カラム、`.tool--offset` で互い違い。ホバーで図版が `rotate(-1.2deg)` 浮く
- 100ドットグリッド（10×10）= 100人。朱が10個 = 左利き。出現は per-dot 12ms delay のポップイン
- スクロール出現は IntersectionObserver + fade-up 0.7s ease-out のみ（パララックス不使用）
- `prefers-reduced-motion`: 動きは止めるが鏡文字の演出（概念の核）は残す

## 実装メモ
